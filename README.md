# TGF — TASIMAS GUI Framework

Repository: https://github.com/tasimas-com/tgf

Retained-mode, data-oriented, damage-driven C++20 GUI framework for large professional applications and games.

The current implementation is an early `tgf::core` foundation, not yet a graphical UI framework. Read the root [TODO.md](TODO.md), [README.md](README.md), [build guide](docs/BUILDING.md), [architecture](docs/DESIGN.md), and [status ledger](docs/STATUS.md) before contributing.
